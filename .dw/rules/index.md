## Overview

winbox-gui is a Tauri 2 desktop application for managing Windows and Linux VM
profiles through Docker/QEMU. The repository combines a vanilla JavaScript
frontend in `src/` with a Rust/Tauri backend in `src-tauri/`.

## Structure

Project type: multi-language single application. There is no workspace
orchestrator, no git submodules, and no independent service boundary. The root
`package.json` drives Tauri and JavaScript checks; `src-tauri/Cargo.toml` owns
the Rust backend and bundled desktop app.

### Communication Patterns

- Frontend to backend: Tauri IPC via `window.__TAURI__.core.invoke(...)`.
- Backend to frontend: Tauri events, mainly `operation-progress` emitted from
  `src-tauri/src/lib.rs`.
- Backend to VM runtime: shell-out to Docker, Docker Compose, `df`, `du`, `cp`,
  `xdg-open`, and platform-specific WSL/VFIO tools.
- VM access: generated Compose files bind noVNC/RDP/SSH ports to `127.0.0.1`.
- Persistence: profile config under XDG/AppData config paths; VM storage under
  XDG/AppData data paths or a validated custom storage directory.
