# Third-Party Notices

This file records the third-party projects and services that are relevant to the
installable Office profile. It is not a complete dependency license report for
the Rust or JavaScript package graph.

## Runtime Integrations

| Component | License | How winbox uses it |
| --- | --- | --- |
| dockurr/windows | MIT | Referenced as the pinned Docker image `dockurr/windows:5.14` for the Windows VM runtime. The image is pulled by Docker and is not bundled inside the winbox `.deb` or AppImage. |
| WinApps | AGPL-3.0 | Cloned by winbox at runtime into the user's data directory and checked out at a pinned upstream commit. WinApps is not vendored, patched, or redistributed inside winbox packages. |
| WinApps-Launcher | GPL-3.0 | Used through the upstream WinApps runtime integration. winbox delegates Office app launch to WinApps-generated launchers and does not bundle WinApps-Launcher artifacts. |
| FreeRDP | Apache-2.0 | Detected on the host as native `xfreerdp` or through the `com.freerdp.FreeRDP` Flatpak. winbox invokes the user's installed FreeRDP client and does not hard-depend on it in the `.deb`. |
| Microsoft Office Deployment Tool | Microsoft software terms | Used to install Office inside the user's Windows VM with the user's license and Microsoft media. winbox stages configuration and installer inputs but does not provide Office, Windows licenses, product keys, or activation. |

## Packaging Notes

- Linux releases intentionally publish only `.deb` and AppImage bundles.
- Docker, Flatpak, FreeRDP, WinApps, Windows and Office are not bundled as hard
  runtime dependencies of the `.deb`; the Office wizard checks and guides those
  prerequisites at setup time.
- On Ubuntu 24.04, AppImage execution may require `libfuse2t64` or the
  AppImage fallback `--appimage-extract-and-run`.
- The MVP does not include `tauri-plugin-updater`; updates are delivered as new
  manual releases while preserving local profile state.

## Office Profile Boundary

The Office profile is a bring-your-own-license flow. winbox does not provide
Windows, Office, Microsoft 365 subscriptions, product keys, activation services,
or license validation. WinApps and its launcher assets remain upstream runtime
artifacts; clean-room scripts generated by winbox are authored separately.
